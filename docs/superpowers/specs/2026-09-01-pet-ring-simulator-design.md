# 宠环模拟器设计说明

本设计以 [PRD v0.1](../../../outputs/梦幻西游宠环模拟器-PRD-v0.1.md) 为唯一产品需求来源。

## 已确认决策

- 产品为部署在 `ring.ddctl.com` 的响应式网页。
- 不设计登录，个人周期、历史和物价只保存在当前浏览器。
- 首次访问明确询问是否参与匿名统计；拒绝不影响使用。
- 公共服务只收集任务及奖励概率需要的最小字段。
- 任务和奖励概率来自全站匿名样本；个人物价不上传。
- 后端使用 Go，公共样本使用独立 SQLite。
- 应用使用独立容器、数据卷和 Docker 网络。
- 仅复用现有 `supabase-caddy` 作为 HTTPS 入口，不使用 Supabase 其他组件。
- 第一版不连接或修改生产服务器，只交付可部署材料。

## 边界

第一版必须完成记环、积分计算、成本统计、平均值回退预测、公共模型预测、奖励档位、本地历史、本地物价、匿名选择、匿名样本 API、SQLite、限流、Docker 和 Caddy 配置示例。

第一版不做账号、跨设备同步、导入导出、排行榜、管理后台和公共物价。

## 可靠性原则

- 没有公共样本时使用当前周期平均积分和平均成本外推，并标记为低可信度。
- 公共样本不足时不得显示伪精确概率。
- 所有客户端输入在服务端重新校验。
- 单条匿名样本永不通过 API 返回。
- 前端网络失败不能阻断本地记账。
- 生产部署必须独立于现有 Supabase 数据和业务网络。
